
# HTML Practice Page

This repository contains a simple HTML webpage created for learning and practicing basic HTML concepts. It was also used to understand how to host a static website using **GitHub Pages**.

The webpage is not a complete application or project. It is a single-page practice website that includes a student information form and links to a few sample learning domains.

## 📚 What I Practiced

* Basic HTML document structure
* Headings and paragraphs
* Forms and input elements
* Radio buttons
* Dropdown menus (`<select>`)
* Textarea
* Hyperlinks (`<a>`)
* Basic page formatting using HTML tags

## 🛠️ Technologies Used

* HTML5

## 🌐 GitHub Pages

This webpage is hosted using GitHub Pages.

## 🎯 Purpose

This repository was created to:

* Practice HTML fundamentals
* Learn how HTML forms work
* Understand website hosting with GitHub Pages
* Explore basic webpage structure before learning CSS and JavaScript
